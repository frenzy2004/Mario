# Asset Provenance

All shipped art and audio assets are original procedural assets generated inside the game code or generated by local repository scripts.

- Sprites, tiles, UI icons, particles, and background shapes are drawn with Phaser Graphics at runtime.
- Sound effects and music cues are synthesized with WebAudio oscillators by `AudioSystem`.
- Level layouts and decorative content are generated by `scripts/generate-content.mjs` from original clockwork-garden patterns.

No Nintendo-owned art, sounds, melodies, names, characters, fonts, or level layouts are used.
